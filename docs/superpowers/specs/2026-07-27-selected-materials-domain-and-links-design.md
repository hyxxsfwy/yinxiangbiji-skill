# 精选资料逐篇审阅与双向链接设计

## 背景与目标

当前 Obsidian vault 的 `30_精选资料`共有 216 篇正文：

- `AI`：188 篇；
- `Quant`：8 篇；
- `投资理财`：18 篇；
- `个人成长`与`软件工程`当前只有目录索引，没有正文。

本次整理逐篇核对文章实际内容与所在 `domain`，将明显错域文章移入
`99_废纸篓`；对保留文章中具有明确内容关联的文档建立受控双向链接。整理必须
可审计、可恢复，不改写人工正文，也不为追求链接数量强行建立弱关系。

## 领域判定

审阅证据固定包括文件路径、frontmatter、标题、首段有效正文、二三级标题和
图片型笔记的实际图片。仅标题或正文偶然出现领域词不构成领域匹配。

### AI

主要内容必须属于模型、Agent、RAG、AI 编程、AI 基础设施、AI 产品与应用、
AI 安全治理、AI 产业或 AI 对工作和社会的直接影响。汽车、婚恋、普通职场、
社会新闻、通用软件工具和硬件文章，即使来源账号名称含“AI”，也不属于 AI。

### Quant

主要内容必须属于量化研究、因子、回测、时间序列、机器学习交易、量化工程或
量化 Agent。泛交易观点但没有量化方法的文章不属于 Quant。

### 投资理财

主要内容必须属于资产配置、市场、交易、财富管理、金融数据、加密资产或行业
投资。人物八卦、婚恋、职场和一般社会新闻不因涉及财富数字或金融人物而归入
投资理财。

## 审阅清单

仓库保存一份 JSON 审阅清单，每篇正文必须且只能出现一次，字段为：

```json
{
  "path": "AI/2026年07月/示例.md",
  "decision": "keep",
  "reason": "正文主要讨论 Agent 架构",
  "topic": "Agent 工程",
  "links": [
    "AI/2026年07月/另一篇.md"
  ]
}
```

`decision`只能为 `keep`或`trash`。`trash`条目不建立自动链接；`keep`条目的
`links`最多三项。执行前验证清单完整覆盖当前 216 篇正文，不接受缺项、重复项、
不存在路径、非对称链接或链接到待删除文档。

## 废纸篓迁移

错域文档保留原领域和月份层级，移动到：

```text
99_废纸篓/
└── 30_精选资料/
    └── <原领域>/
        ├── _attachments/
        └── <YYYY年MM月>/
            └── <原文件名>.md
```

移动前创建 ZIP 备份和 SHA-256 清单。文章引用的本地图片和附件复制到废纸篓
镜像 `_attachments`，保持原相对链接可用。原领域附件不删除，因为同一附件可能
被保留文章共享；后续可在独立任务中清理孤立附件。

目标已存在且内容相同时视为幂等；目标同路径异内容或类型不一致时，执行前中止。
任何写入失败都保留源文档，并通过备份恢复本次已经修改的 Markdown。

## 自动双向链接

自动链接只表达共享问题、方法、技术机制、同一事件的不同分析或明确的上下游
关系。仅同属“AI”或标题中共享一个常见词不构成关联。

链接写入独立受控区块：

```markdown
## 相关笔记

<!-- llmwiki:auto-links:start -->
- [[30_精选资料/AI/2026年07月/另一篇|另一篇]]
<!-- llmwiki:auto-links:end -->
```

执行器完整替换该区块，不修改区块外正文。每篇最多三条自动链接；每一条
`A → B`必须同时存在`B → A`。没有强关联的文档不创建区块。链接目标使用
vault 根路径，不依赖源文件相对位置。

## 执行流程

1. 只读加载 `30_精选资料`并验证审阅清单覆盖全部正文；
2. 预检废纸篓目标、附件引用、链接对称性和三链接上限；
3. 在 `80_系统/知识库治理/变更快照`创建 ZIP 和 SHA-256 清单；
4. 复制待移动文档引用的图片和附件；
5. 把错域 Markdown 移入废纸篓镜像目录；
6. 在保留文档中写入受控自动链接区块；
7. 重建各领域 `目录索引.md`；
8. 在 `80_系统/知识库治理/审核日志`写入逐篇审阅报告；
9. 验证文档总数守恒、图片与内部链接可解析、自动链接对称且每篇不超过三条。

预览模式不创建目录、备份或报告，只输出保留数、移入废纸篓数、链接边数和全部
冲突。执行模式要求固定确认词 `CURATE_SELECTED_MATERIALS`。

## 验收标准

1. 原始 216 篇正文全部具有独立审阅结论；
2. `30_精选资料`不再包含实际内容与所在领域明显不符的文档；
3. 所有错域文档均位于 `99_废纸篓/30_精选资料`镜像路径；
4. 移入废纸篓的文章仍能解析其本地图片和附件；
5. 自动链接全部双向，每篇最多三条，没有指向废纸篓或不存在文档的链接；
6. 无明确关联的文档没有自动链接区块；
7. 各领域目录索引与当前保留文档一致；
8. ZIP、SHA-256 清单和逐篇审核日志存在且可读取；
9. `restructure_obsidian_vault.py --verify`继续通过。
