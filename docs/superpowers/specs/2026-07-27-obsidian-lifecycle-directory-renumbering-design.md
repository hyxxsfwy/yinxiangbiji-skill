# Obsidian 生命周期目录重新编号设计

## 背景

用户已经在 `D:\OneDrive\文档\@_Obsidian` 手工完成生命周期目录调整：

- `90_系统` 改为 `80_系统`；
- `99_归档` 改为 `90_归档`；
- 新增 `99_废纸篓`；
- `Bases`、模板、知识库治理和迁移记录均位于 `80_系统`。

本设计把该结构设为仓库文档、脚本和验证器的唯一有效契约。旧名称只作为自动迁移来源存在，不再作为兼容结构接受。

## 目标

1. 所有新建、导出、治理、迁移和验证逻辑使用新目录编号。
2. `restructure_obsidian_vault.py` 自动把旧生命周期目录迁入新结构。
3. 自动迁移不覆盖同路径异内容文件，并具备快照、验证和失败恢复能力。
4. 已经手工完成新结构的 vault 重复执行保持幂等。
5. 文档、模板、测试和生成内容不再把旧目录描述为当前路径。

## 唯一有效目录


`10_项目`、`20_知识笔记` 和 `30_精选资料` 的业务结构与领域规则保持不变。

## 自动迁移

### 映射

| 旧目录 | 新目录 |
|---|---|
| `90_系统/**` | `80_系统/**` |
| `99_归档/**` | `90_归档/**` |

`99_废纸篓`没有旧目录来源，由脚本确定性创建。

### 预检

预览和执行都先扫描两个旧目录及对应目标：

- 目标不存在时，记录为新增；
- 同路径文件存在且 SHA-256 一致时，记录为可合并重复项；
- 同路径文件存在但 SHA-256 不同时，记录为冲突；
- 文件与目录类型不一致时，记录为冲突。

只要存在冲突，执行模式就在创建迁移写入前终止，并列出全部冲突。预览模式只输出映射、文件数量和冲突，不创建目录、快照或报告。

### 执行与恢复

执行模式复用现有受控迁移流程：

1. 对旧知识库目录和旧生命周期目录建立完整文件清单；
2. 创建 ZIP 快照并逐文件记录大小和 SHA-256；
3. 把旧生命周期文件复制到新目录，跳过同内容重复项；
4. 创建 `99_废纸篓`及新结构必需路径；
5. 生成或更新模板、治理资产、首页和索引；
6. 验证目标文件、链接、图片、清单和快照；
7. 验证通过后清理旧目录；
8. 清理失败时，从已验证 ZIP 恢复所有旧来源并抛出原始错误。

现有 vault 已不存在旧目录时，不执行生命周期复制和清理，只补齐缺失的新目录并验证，因此重复执行幂等。

## 脚本契约

### `restructure_obsidian_vault.py`

- 结构生成路径由 `90_系统`改为 `80_系统`；
- 归档路径由 `99_归档`改为 `90_归档`；
- 新增 `99_废纸篓`；
- 迁移记录固定写入 `80_系统/迁移记录`；
- 内部链接和生成文本使用新路径；
- `--verify`要求三个新目录存在，并把旧 `90_系统`、`99_归档`视为验证失败；
- 历史旧知识库目录仍按现有映射迁移。

### `sync_to_obsidian.py`

统一 LLM Wiki 根目录检测使用 `10_项目`、`20_知识笔记`、`30_精选资料`和 `80_系统`。检测到该结构时继续拒绝全量同步直接写入正式 vault。

### 精选导出

`export_search_results.py` 的领域目标仍为 `30_精选资料/<领域>`，不受本次编号调整影响。索引、图片和附件规则保持不变。

## 文档契约

同步更新以下权威材料：

- `README.md`；
- `SKILL.md`；
- `references/obsidian-knowledge-management.md`；
- 当前模板或生成文本中的系统、归档和废纸篓路径；
- 文档契约测试。

旧设计和实施计划保留为历史记录，不批量改写正文；被直接取代的上一版目录设计在文件头标注本设计链接。

## 测试与验收

自动测试至少覆盖：

1. 新结构精确目录树；
2. 旧 `90_系统`自动迁入 `80_系统`；
3. 旧 `99_归档`自动迁入 `90_归档`；
4. 自动创建 `99_废纸篓`；
5. 同路径同内容文件安全合并；
6. 同路径异内容文件在写入前中止；
7. 复制或清理失败后恢复旧来源；
8. 新结构重复执行幂等；
9. `--verify`拒绝残留旧目录；
10. 全量同步保护识别 `80_系统`；
11. README、Skill、参考文档和生成内容只把新目录作为当前契约。

完成实现后执行：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q scripts tests
git diff --check
python scripts/restructure_obsidian_vault.py --vault "D:\OneDrive\文档\@_Obsidian" --verify
```
